PAYMENT GATEWAYS INTEGRATED (6 Major SA Providers)
================================================================================

PRIORITY 1: PAYFAST
  - Fee: 2.9%
  - Min/Max: R10 - R999,999
  - Processing: Instant
  - Type: Credit/Debit cards
  - Webhook: Yes (MD5 signature)
  - Status: Most popular in SA

PRIORITY 2: STRIPE
  - Fee: 2.9%
  - Min/Max: R10 - R999,999
  - Processing: Instant
  - Type: International cards
  - Webhook: Yes (HMAC-SHA256)
  - Status: Backup/International

PRIORITY 3: YOCO
  - Fee: 2.5% (lowest local)
  - Min/Max: R10 - R999,999
  - Processing: Instant
  - Type: Cards + Bank accounts
  - Webhook: Yes (optional signature)
  - Status: SA Fintech leader

PRIORITY 4: EFT / BANK TRANSFER
  - Fee: 0% (user pays bank fee)
  - Min/Max: R10 - R999,999
  - Processing: 1-2 days
  - Type: Direct bank transfer
  - Webhook: Manual verification
  - Status: Low cost, slower

PRIORITY 5: VODACOM M-PESA
  - Fee: 0%
  - Min/Max: R10 - R40,000
  - Processing: Instant (STK)
  - Type: Mobile money
  - Webhook: Yes (STK callback)
  - Status: SMS/app prompt to user

PRIORITY 6: MTN MONEY
  - Fee: 0%
  - Min/Max: R10 - R50,000
  - Processing: Instant
  - Type: Mobile money (USSD/App)
  - Webhook: Yes or polling
  - Status: MTN subscribers

DATABASE SCHEMA - PHASE 2 NEW COLLECTIONS
================================================================================

Collection: paymentTransactions
Document structure:
  {
    userId: string
    paymentRequestId: string (links to Phase 1)
    gateway: "payfast|stripe|yoco|eft|vodacom_mpesa|mtn_money"
    gatewayTransactionId: string (from payment provider)
    amount: number
    currency: string (ZAR)
    status: "pending|processing|success|failed|cancelled"
    errorMessage?: string
    errorCode?: string
    metadata: {
      source: "fine|appointment",
      sourceId: string,
      returnUrl: string,
      webhookProcessed: boolean
    }
    createdAt: timestamp
    updatedAt: timestamp
    completedAt?: timestamp
  }

Collection: storedPaymentMethods
Document structure:
  {
    userId: string
    gateway: "payfast|stripe|yoco|eft|vodacom_mpesa|mtn_money"
    type: "card|bank|wallet|eft"
    
    // Card fields (if type == "card")
    cardNumber: string (masked, last 4 only)
    lastFourDigits: string
    cardholderName: string
    expiryMonth: number
    expiryYear: number
    
    // Bank fields (if type == "bank" or "eft")
    accountNumber: string
    branchCode: string
    bankName: string
    accountHolder: string
    
    // Wallet fields (if type == "wallet")
    walletId: string
    phoneNumber: string
    
    // Common
    isDefault: boolean
    isActive: boolean
    createdAt: timestamp
    lastUsedAt?: timestamp
  }
